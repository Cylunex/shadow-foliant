# Foliant Backtest Review

## 何时使用

用户需要验证策略在给定 A 股集合和历史区间中的表现、风险或相对基准结果时使用。
它只产生研究预览，不用于模拟或触发真实券商执行。

## 固定顺序

1. 明确证券集合、开始与结束日期、策略、持有天数、止损、止盈、最大持仓和基准。
2. 检查开始日期早于结束日期，证券不超过合同上限，基准为明确的 A 股指数代码。
3. 调用 `foliant.backtest.preview` 创建持久化 Run，并保留同一意图的幂等键。
4. 使用 `foliant.run.get` 等待终态；运行阶段不可强制终止时如实说明。
5. 完成后调用 `foliant.run.result`，按 continuation 分页读取必要部分。
6. 核对样本区间、基准、佣金、印花税、滑点、下一交易日成交和价格限制。

## 复核重点

- 区分样本内表现与未来收益；检查交易数是否足够。
- 检查最大回撤、波动、胜率、盈亏比和相对基准，而不只看总收益。
- 说明幸存者偏差、数据缺失、停牌、涨跌停和可能的选择偏差。
- 若 `warnings` 非空，降低结论置信度。

## 禁止行为

- 不触发选股发布、成交录入、组合修改、MiniQMT、下单或撤单。
- 不把回测曲线描述为未来收益承诺。
- 不使用结束日期之后的事实解释历史信号。
- 不请求或暴露完整逐笔数据、机器凭据或内部路径。

详细检查见 [references/backtest-validity.md](references/backtest-validity.md)。
