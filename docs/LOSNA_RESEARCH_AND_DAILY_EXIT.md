# 早盘指数、个股超限日报与 Losna 研究入口

原生任务中心在14:30生成个股超限日报，之后每10分钟核对同日业务键，包含休市日。
个股上限15，同代码多个批次合并，ETF按官方基金元数据单列，其他基金与未知记录分别计数。
日报使用已有最终风险动作，可卖量待核时仅展示退出复核。实际成交入账后才减少只数。

调用渠道前在既有研究修订表持久化。明确HTTP拒收最多尝试三次，已接受渠道不重发。
超时或在途未知保留unknown供核收。账本不可读时，可按上次超限记录发当日待核提示。
恢复后重新生成正式建议。正文沿用压缩、加密存档和渠道回执。

超限日报第二行比较同一账户在上海自然日上一天已有渠道受理的超限日报。两期须有同一持仓、
当日可用的供应商行情和已确定的最终风控动作。按当期退出复核优先级展示一条变化，
列出两次行情时间和当期原因。可比动作全相同时给出覆盖只数，缺昨日回执或可比行情时给出缺口。
升级前的日报只对照实际归档的复核项。记录比较结果不会更改风险动作或触发额外投递。

五指数保存点位、开盘、前收、涨跌幅和供应商报价时间。固定报告两行展示，
历史缺点位时注明待核。风险等级与事件去重沿用原规则。

Losna入口是 agent/skills/foliant-operator/SKILL.md。用项目Python 3.12执行
scripts/foliant --config /path/to/private/config.json catalog，call claim/status/submit从stdin读JSON。
同目录有公开研究与私人持仓的两套配置示例。操作范围限制在研究包和回执。

09:58准备盲提名和点名复核。盲提名从manifest的独立特征筛正PE、正现金质量、60日收益为负的完整样本，
按PE与代码稳定选前100，记录范围和版本；最多提交3项与证据引用。已核问财只参与点名观察。
17:20幂等登记已接收盲提名至原后验管道，并准备策略证据复核和私人账户预览。
策略复核解释已保存的模型账本和实验，新因子及正式参数继续使用既有晋级流程。

Losna的foliant_research可信定时处理器使用独立DSH上下文，无聊天记忆、原生工具和外发工具。
它调用真实JSON CLI回传产物，超时按原键查回执，同批有效的研究可进入原生报告一行。
股票报告仍由Foliant生成并投递。

部署时需配置两套受限CLI连接和可信提醒时点。隔离验证覆盖数据库、实际CLI、Losna执行调用、
通知压缩、加密存档和渠道替身。真实模型、生产配置、自然投递及长期投资效果分别验收。

盘前列供应商带日期的已核收盘；盘中与午报统一展示五指数点位和涨跌幅，
缺失字段明确待核。未知浮盈亏不再按零收益归入健康或长期横盘。

明确拒收且未有渠道接收时，重试采用新持仓；降回15只则关闭未送达义务。
已有接收的稿件冻结，异常保留已接收回执。研究领取带运行键和3分钟租约，
过期终结、重新领取递增代次；旧工作不能覆盖新回执。
Losna模型输出先落盘，再通过原键提交，恢复时复用输出；单次研究至多60秒、
2步；逐票研究总token预算8192，策略聚合核验4096，均包含推理消耗。使用现有DeepSeek时
采用low推理，理由及反证各不超过200字、后续核查不超过300字。有效期之后的研究
不再作为当前盘面解释。

旧清仓助手与尾盘复盘也使用同一分类服务：个股上限15、ETF与其他基金分别列示，
合计证券数不再触发个股瘦身；部分减仓不计作释放名额。旧入口传入20也受15上限约束。
模型提示中的未知盈亏与持有日期均保持待核，并明确左侧偏好及既定风险动作边界。
午休展示同日已核实的午间收盘点位，保留11:30时刻；陈旧非收盘报价仍拒绝。

研究v2在同一manifest上冻结并缓存公开财务与量价特征，按股票代码前四位分片，
不保存账户数量或成本。盲提名、点名复核与持仓复盘共用这些公开事实，保留冻结行情
截止、输入哈希和财务修订集；已有缓存不重算整池。点名候选附逐票特征证据引用，
私人复盘额外读取本账户既有最终动作、组合保护与价位，缺失部分继续标记。
策略核验同时读取已有1/3/5/10/20日价格后验，严格区分价格标签与可执行净收益。
v2盲提名单独以losna-blind-v2进入影子后验，与v1样本分开，不自动激活正式政策。

盘后研究使用同日15点之后的供应商收盘标记，沿用既有账户预览的post_close口径，
不把收盘价标成盘中可执行价；前一日收盘仍待核。研究输入不包含重复读取时产生的
plan_id、created_at与expires_at，避免只有读取时间变化就产生新工作。
策略证据按预算投影实验摘要与1/3/5/10/20日分组指标，保留全量来源哈希、原组数、
展示组数与截断标记，优先保留问财/OpenAPI/Losna及有样本的组；不改变原始收益、
有效样本或晋级阻断值，也不把被省略的原始数组视为已经审阅。

供应商在午休内可能再次发布指数（实测12:05）。同日午休重发按“午间参考+供应商时刻”
展示，不作为盘中可执行行情；13点开盘后仍恢复盘中时效检验，不延用午间旧值。
