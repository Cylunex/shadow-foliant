# 早盘指数、个股超限日报与 Losna 研究入口

原生任务中心在14:30生成个股超限日报，之后每10分钟核对同日业务键，包含休市日。
个股上限15，同代码多个批次合并，ETF按官方基金元数据单列，其他基金与未知记录分别计数。
日报使用已有最终风险动作，可卖量待核时仅展示退出复核。实际成交入账后才减少只数。

调用渠道前在既有研究修订表持久化。明确HTTP拒收最多尝试三次，已接受渠道不重发。
超时或在途未知保留unknown供核收。账本不可读时，可按上次超限记录发当日待核提示。
恢复后重新生成正式建议。正文沿用压缩、加密存档和渠道回执。

五指数保存点位、开盘、前收、涨跌幅和供应商报价时间。固定报告两行展示，
历史缺点位时注明待核。风险等级与事件去重沿用原规则。

Losna入口是 agent/skills/foliant-operator/SKILL.md。用项目Python 3.12执行
scripts/foliant --config /path/to/private/config.json catalog，call claim/status/submit从stdin读JSON。
同目录有公开研究与私人持仓的两套配置示例。操作范围限制在研究包和回执。

09:58准备盲提名和点名复核。盲提名从manifest的独立特征筛正PE、正现金质量、60日收益为负的完整样本，
按PE与代码稳定选前100，记录范围和版本；最多提交3项与证据引用。已核问财只参与点名观察。
17:20幂等登记已接收盲提名至原后验管道，并准备策略证据复核和私人账户预览。
策略复核解释已保存的模型账本和实验，新因子及正式参数继续使用既有晋级流程。

Losna的foliant_research可信定时处理器使用独立DSH上下文，无聊天记忆、原生工具和外发工具。
它调用真实JSON CLI回传产物，超时按原键查回执，同批有效的研究可进入原生报告一行。
股票报告仍由Foliant生成并投递。

部署时需配置两套受限CLI连接和可信提醒时点。隔离验证覆盖数据库、实际CLI、Losna执行调用、
通知压缩、加密存档和渠道替身。真实模型、生产配置、自然投递及长期投资效果分别验收。
