# 选股行业输入与任务状态修复

本次针对 [运行检查](SELECTION_FLOW_AUDIT_2026-09-22.md) 发现的行业缺失、主数据长期未发布、
独立量化行业集中和同步状态失真进行修复。代码变更尚未部署，不代表线上榜单已经变化。

## 行业数据与当前股票池

只读检查确认已有申万文件覆盖旧股票池全部 5,569 个代码，共 31 个一级行业，无冲突。
此前该文件只用于持仓分析，没有进入选股。这个覆盖率仅对应被检查的旧股票池；新上市
代码仍须在同步时重新核验。

- 分类计算现在处理全市场；持仓显示仍最多 100 行。分类的生效、更新、文件观测时间均
  参与可用性判断；分类和来源哈希随证券快照保存，选股与重放不再读取实时 CSV。
- 主数据发布区分当前上市池与完整生命周期。只有来源明确提供上市状态，且数量、重复
  代码、交易所覆盖检查通过时，才可发布当前池。切换用途时按同样的上市成员口径比较数量。
- 当前上市池不能用于事后补建退市历史；历史生命周期查询回退至原有生命周期快照，
  不将缺失退市集合解释成历史上从不存在。
- 08:35 盘前与 20:05 盘后补跑独立检查主数据，即使行情已经完整也不能跳过股票池缺口。
  09:45 选股保持原有盘前决策边界；边界之后才补入的新快照不能倒填至早先决策。

## 新运行的规则

| 项目 | 新规则 |
| --- | --- |
| 输入闸门 | 行业覆盖至少 90%，证券快照年龄最多 7 个自然日 |
| 未分类股票 | 不进入新正式榜单与独立量化榜单 |
| 正式 TOP15 | 恢复已有同业上限，默认最多 5 只，可由原配置收紧 |
| 正式 TOP5 | 同一行业最多 2 只；约束不足以填满时不放宽 |
| 独立量化 | 新版本 `codex-independent-v2`，财务与 PE/PB 在行业内比较 |
| 独立行业样本 | 每行业至少 5 个必需字段完整且有限的候选，不对极小组退回全市场排名 |
| 独立榜单集中度 | TOP15 同业最多 3 只；TOP5 同业最多 1 只 |
| 独立五维权重 | 保持质量 30、趋势 25、估值 20、流动性 15、风险 10 |

新策略清单记录行业规则、参数和哈希。旧清单继续使用 v1 语义及原输入，旧结果不重写。
外部研究接口兼容两个版本，并保留实际底座版本。行业校正不是强制每日换股，也不构成
收益改善的实证；重复率和新行业分布需在部署后观察新运行。

## 任务状态与操作边界

- 主数据或行业覆盖失败时，研究同步不能再只因行情成功而记为完整成功；估值晚到也不能
  掩盖主数据错误。历史日志中的主数据不完整会在定时快照中显示降级。
- 正式结果 API、定时快照、健康检查和通知呈现行业覆盖及主数据质量；候选显示行业。
- 持仓深度周报及 AI 压力分析已经按用户选择在运行配置中关闭；本次代码不扩大关闭范围。
- 工作日研究心跳原先先执行发送命令，再做公开研究，且没有把研究保存为当期 bundle。
  已准备“读取 → 研究 → 提交 → 发送一次”的提示修订，但自动审批拒绝持久更新，等待用户
  明确授权。现有心跳尚未修改，不能宣称外部研究陈旧问题已在线修好。
- 本次只做本地代码提交，不推送、不部署，不执行证券交易。上线还需明确部署指令；部署
  后由正常同步创建新快照，无需修改旧数据或迁移表结构。
