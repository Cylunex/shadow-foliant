# 低价擒牛

低价擒牛保留为正式的本地 PIT 卫星策略，不依赖问财产生正式候选。问财仍并行运行，
只做外部参考和结果复核。

## 当前规则

- 股价严格小于 20 元；20 元本身不入选。
- 净利润同比增长至少 100%。
- 经过统一的上市状态、ST、停牌、历史长度、成交额和涨跌停可交易性门槛。
- 数据存在时，要求净利润为正、营收不下降、经营现金流/净利润至少 0.5。
- 最近三期财报数据存在时，净利润和营收增长至少两期为正。
- 净利暴增但营收下降的低基数或一次性增长候选会被排除。

最终在通过硬条件的股票中，综合比较增长、现金质量、估值、60 日残差趋势、最大回撤
和成交额流动性。成交额只用于排除难交易标的和寻找合适区间，不再奖励最冷门股票。

## 在正式选股中的位置

低价擒牛是独立策略族，与主力资金、低估值同属高优先级卫星来源。它可以提名正式
TOP15，但仍受卫星配额、行业集中度和相关性约束。小市值与净利增长的重复命中会按同一
策略族去重，不会削弱低价擒牛的独立确认。

## 回测口径

- T 日收盘后出现信号，最早 T+1 日开盘成交。
- 一字涨停不能假设买入，一字跌停不能假设卖出。
- 佣金包含最低 5 元，印花税按成交日历史税率处理。
- 单笔买入默认不超过当日成交额的 10%；缺少可靠成交额时不猜测单位。

历史结果不保证未来收益。本策略是候选发现工具，不构成投资建议。
