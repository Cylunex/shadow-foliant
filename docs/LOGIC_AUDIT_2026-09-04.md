# 0.6.0 主链路逻辑走查与闭环修复

基线：`5a8b374`。本轮是代码走查、缺陷修复和隔离测试，不是生产部署或收益验证。
三轮分别检查正常流程、失败/重跑、跨模块与长期运行一致性；未修改正式选股偏好和盘前/盘中通知模板。

## 第一轮：入口 → 业务 → 输出

| 链路 | 检查/修正 |
|---|---|
| 数据 → PIT → 三赛道 → TOP15/TOP5 | 核对估值有界滞后、质量分、行业最多 5 只、三赛道及外部参考隔离；保留现有规则 |
| 成交导入 → 幂等识别 → 持仓 | 非有限数字（NaN/Inf）现在作为输入错误处理，不能进入成交价格或费用 |
| 账户收益查询 | 区间汇总严格使用请求的 N 条明细；本月累计仍独立按月计算 |
| 行动预览 → 风险快照 | 传递停牌标记；过期行情不再构成“完整”风险快照；现金未知时明确证券子账分母 |
| 报价 → 市值 | 保留 ETF 等三位小数报价精度，乘数量后才按金额四舍五入，避免先舍入单价造成误差 |
| Agent 起草 → Web 编辑 → 锁定 | 编辑保留并重算原引用；重复确认同一草稿幂等；到期时刻按 UTC 比较 |
| 数字引用 | 正数不能从负数片段中截取；引用/到期时间要求带时区 |
| 私人输入 → 后续查询 | 本机 operator 可读取草稿版本、概率判断和账户预览，公共 Agent 权限不扩大 |

带引用的锁定在基线测试中已可用；不是本轮修复的“崩溃”。实际修复的是引用编辑、时区和重复确认。

## 第二轮：失败 → 可见状态 → 恢复/终止

- Case 已写入、事件尚未入队时发生中断：再次执行 seed 会幂等补齐事件和待办。
- 调查结果进入公共摘要查询及 Web；不暴露原始材料全文或私人论点。
- 调查预留后中断：重跑标为 interrupted 并终止该次模型预算，不会伪称完成或重复花费。
- 单个调查失败不阻断同批其他调查；错误类别留档。
- 人工可备注“已复核”事件；确认只影响本人待办，不等于证据已证明，也不解除硬风险。
- MCP 创建的账户预览可在 Web 读取、核对、确认；确认后可查事实记录。
- 成功确认后即使后续成交水位改变，重复请求仍返回原成功结果；未成功的旧预览继续拒绝。
- Web 输入和版本冲突返回 422/409，而不是无差别 500。
- 原主源异常可进入备用行情路由；公司行为/研究旁路失败不撤销已完成的模型结算，并明确返回 partial。
- 已归档的原日执行事实可关闭缺口任务，同时恢复连续账本和独立选股对照组。
- “缺事实”与“目标登记太晚”分开：缺原日事实继续待补，不能七天后永久丢掉可恢复的模拟意图。
- 盲测揭示后失败，可用受信运维 CLI 记录原因并退役；已揭示区间永不重新开放为盲测。

```bash
python scripts/evaluate_sealed_holdout.py --batch BATCH_ID --trial TRIAL_ID \
  --void-reason "已核查：评估进程中断，放弃该批结果" --confirm-consume
```

## 第三轮：长期运行、证据与权限

- 独立对照组仅从本轮有事实的日期/证券中选待结算项，旧缺口不会占满前 500 行而饿死新数据。
- 队列数量、重试预算必须是有界整数；payload 不能覆盖真实 work_id/attempt。
- 历史未知公司行为会污染后续现金/股数，不能在清仓或当天行情齐全后自动升级为 verified。
  恢复信任需要原始事实与可审计重建，不能靠切换布尔值消除历史缺口。
- 开发评估也执行冻结协议；开发结果只能标候选就绪，不直接当最终晋级凭证。
- 严格评估绑定 trial/dataset/code/formula/cost_model、输入回执和执行事实；观察时刻不能晚于决策，决策不能晚于执行。
- 风险调整指标明确为净超额减去相对基准的额外最大回撤百分点；缺回撤事实拒绝，不再混用普通净超额。
- 最终评估保留协议、公式/数据/代码版本和实际求值行摘要哈希。
- 证据哈希包含日期和数值。同样收益发生在新日期，不再被误认成同一次证据；统计汇总相同不代表输入相同。
- 委员会的单次预算覆盖真实路由调用，不允许隐藏 fallback 扩大；无模型时保留不动/规则对照，不伪造 LLM 提案。
- 原文归档遇到权限过宽的既有文件会拒绝，不因内容哈希相同而忽略权限。
- 新确认/账户读取接口均为 ADMIN；公共 Agent 不获得私人确认能力。

保留的实际限制：

- 全公司行为覆盖、现金/税额、历史缺失行情和预测结果必须来自真实输入；缺失继续显示未核实/待裁决。
- 模型和容器真实效果不由合同测试代替，本轮未调用生产模型或部署服务。
- 连续混合政策账户不是新政策的纯收益证据；不足以核验时继续禁止自动增风险，不用放宽门槛制造进化结果。
- 走查与测试降低已识别风险，不构成“全部线上场景无缺陷”的保证。
