# 持仓与成交使用说明

持仓、成交、分析历史与监测状态统一存储在 PostgreSQL。Stock Web 中这些页面和所有写操作仅对 `stock-admins` 开放；系统尚未完成 `shadow_user_id` 级金融数据隔离，不宣称多租户。

## 使用边界

- 通过 Stock Web 查看持仓、导入成交、修正持仓与触发分析。
- 成交是可追溯事实；修正应留下变更记录，不以本地数据库文件覆盖生产状态。
- 任务与 Agent 在服务端读取持仓，浏览器不会取得数据库或 Media 服务凭据。
- 邮件、QQ 或 Webhook 未配置或投递失败时，通知保持待发，不伪装成功。

## 股票持仓绩效

持仓页的 TWR、风险与基准曲线共用现金流调整后的收益序列。买卖金额按两个快照之间
的整个区间归集，快照缺日也不会遗漏中间成交；调整记录不作为买卖现金流。
最大回撤从累计收益曲线的高点计算，减仓本身不会成为亏损，追加资金也不能抹掉已有回撤。

这是股票市值口径的估算，不含账户闲置现金，净买卖按区间末归集；不是已包含全部现金、
分红与费用的完整账户净收益。XIRR 与快照首末日期对齐，以期初市值为初始资本，只包含
区间内成交和期末市值。期初日期以前及期末日期以后的成交不进入本期校验；区间内缺失
金额仍阻止收益计算。同日收支相抵、非有限数值或缺少正负现金流时不显示年化收益。

异常快照、重复/倒序日期、现金流读取失败或越过既有单区间 ±50% 异常边界时，保留缺口
提示，不删除异常区间再拼接漂亮曲线。较短样本仍不计算年化波动或夏普。指数首末日期
未与持仓快照对齐时不输出超额收益，不能把旧指数收盘与更新的组合市值相比。

计算口径参考 [Portfolio Performance 的现金流与收益说明](https://help.portfolio-performance.info/en/concepts/performance/time-weighted/)
及 [Empyrical 的累计收益回撤计算](https://github.com/quantopian/empyrical/blob/master/empyrical/stats.py)，
未复制第三方实现或新增依赖。

## 运维

生产备份使用受限基础设施中的 PostgreSQL 原生备份流程。仓库和应用目录不创建、同步或恢复 `.db` 文件。部署前后应核对持仓/成交行数、任务状态、下一项定时任务和脱敏日志。

详细生产连接、备份和恢复步骤保存在仓库外私密运维文档中。
