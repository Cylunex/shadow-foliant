# 持仓与成交使用说明

持仓、成交、分析历史与监测状态统一存储在 PostgreSQL。Stock Web 中这些页面和所有写操作仅对 `stock-admins` 开放；系统尚未完成 `shadow_user_id` 级金融数据隔离，不宣称多租户。

## 使用边界

- 通过 Stock Web 查看持仓、导入成交、修正持仓与触发分析。
- 成交是可追溯事实；修正应留下变更记录，不以本地数据库文件覆盖生产状态。
- 任务与 Agent 在服务端读取持仓，浏览器不会取得数据库或 Media 服务凭据。
- 邮件、QQ 或 Webhook 未配置或投递失败时，通知保持待发，不伪装成功。

## 运维

生产备份使用受限基础设施中的 PostgreSQL 原生备份流程。仓库和应用目录不创建、同步或恢复 `.db` 文件。部署前后应核对持仓/成交行数、任务状态、下一项定时任务和脱敏日志。

详细生产连接、备份和恢复步骤保存在仓库外私密运维文档中。
