# 选股表现复盘

用固定提名日期区间和固定持有窗口检查正式 TOP15、TOP5、本地赛道及独立参考。
只读入口不会刷新行情、更新后验、调用模型、修改权重或发送通知：

```bash
.test-venv/bin/python scripts/selection_performance.py \
  --start 2026-10-17 --end 2026-10-23 --as-of 2026-10-23 --horizon 1
```

`--start/--end` 按提名业务日期包含两端；`--as-of` 是收益终点日期上限。输出为 JSON，
使用当前存储的后验标签，不能冒充历史时刻已知信息的完整回放。

## 口径

- 使用既有次日开盘到窗口末日收盘的前复权价格观察标签，保留策略与指标版本。
- 提名必须留在分母内，缺失标签不当作亏损或零收益。`awaiting_outcome_count` 可能是
  尚未成熟，也可能是行情/后验缺失，须结合日历和采集记录判断。
- 单批全部提名均有有效标签、观察区间和指标版本一致时，才输出该批平均收益及胜率。
  汇总对完整批次等权；同时显示全部批次数、完整批次数和成熟提名数，避免只挑成功样本。
- TOP5 与 TOP15 仅比较同一选股运行、同一策略版本、同一观察区间和指标版本的完整批次。
- 不同策略可能具有不同成熟日期和覆盖率，不能仅凭汇总值排行；重叠日期与重复股票不是
  独立样本。价格标签不包含手续费、滑点、涨跌停可成交性或 T+1 约束，不是实盘收益。
- 当前工具不计算市场基准，明确输出 `benchmark_status=not_evaluated`；不能把价格收益称为
  超额收益。策略升降级仍须经过已有独立、可执行净收益验证门禁。

## 本轮可靠性修复

后验更新会跳过每个提名已成熟的持有周期，保留原评估时间和基准字段；同一轮内复用同股票、
同信号日期的行情，最多读取最长持有窗口需要的记录。全量历史纠错须使用独立、显式流程，
不能依赖每天自动重算已成熟结果。

基金资料先把 pandas 缺失值规范为 JSON null，再比较资料变化；单只基金刷新失败保存可重试
状态并继续后续持仓。百度概念响应逐层验证类型并保留有效同级项；拒绝/未知结构返回空值，
这不代表外部接口已恢复可用。

后续数据源修复将路由与缓存的判空标准收口：字段齐全但内容全空、或显式失败的字典会记录
源失败并继续降级。财联社普通快讯改用与加红电报相同的公开 Web 签名接口，普通快讯请求
全分类，加红电报保持原分类。请求失败或响应结构不符仍返回空值。

百度已分类归属缺失时，东方财富补充 `unclassified_boards`。该接口混合行业、概念、地域等
板块，分类字段保持空值并标记 `mixed_unclassified`；这些关联板块只展示事实，不进入热点
题材匹配、龙头判断或正式因子。已经可用的百度分类优先保留，不能被低精度补充结果覆盖。

## 参考项目与取舍

- [Microsoft Qlib：PortfolioMetrics](https://github.com/microsoft/qlib/blob/main/qlib/backtest/report.py)
  分开记录收益、成本和基准。本项目借鉴其口径分离：明确标记费用未计入、基准未计算，
  不将现有价格标签升级为组合净收益，不引入大型训练框架。
- [daily_stock_analysis：BacktestEngine](https://github.com/ZhuLinsen/daily_stock_analysis/blob/main/src/core/backtest_engine.py)
  将历史分析对应到固定前向窗口，数据不足时单独返回状态。本项目借鉴固定窗口及纯函数
  计算分层，同时保留全部提名分母、完整批次与同批次精选对照。
- [a-stock-data：接口变更记录](https://github.com/simonlin1212/a-stock-data/blob/main/CHANGELOG.md)
  记录百度概念接口返回 10003 后替换接口的经历。本轮本机及服务端公开探测也返回 10003，
  后续已验证东方财富关联板块接口能返回数据，但未提供可靠类别；借鉴其替代方向，同时
  保留未分类状态，不能宣称行业/概念分类已完全恢复。

以上借鉴评估和错误处理方法，未复制第三方实现或加入新依赖。
