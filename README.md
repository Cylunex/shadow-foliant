# Shadow Foliant

Shadow Foliant 是面向个人投资研究的股票、基金与市场分析工作台。它帮助整理信息、形成研究
过程和持续跟踪判断，不替代券商交易系统，也不把模型输出包装成确定性收益承诺。

## 理念

- 行情、持仓、研究证据和策略判断分层保存；
- 每个结论尽量能追溯到数据来源和计算过程；
- Agent 用于采集、归纳和提醒，最终交易决策仍由用户完成；
- 与 Ledger 只交换估值和现金流摘要，不复制日常财务账本。

## 主要功能

- 股票、基金、行业和宏观数据整理；
- 自选、持仓、组合与净值分析；
- 本地 PIT 正式选股、五组本地参考策略、技术指标、龙虎榜和策略研究；
- 新闻流、公告、研究资料与 RAG 检索；
- 定时任务、监控提醒和 WebUI；
- 面向 Agent 的研究工具与数据边界。

## 本地开发

按 `.env.example` 准备被忽略的本地配置后，使用项目 Python 环境运行 WebUI、任务中心或测试。
任何行情账号、模型凭据、数据库连接和通知 Token 都不得写入仓库。

```bash
pytest
```
