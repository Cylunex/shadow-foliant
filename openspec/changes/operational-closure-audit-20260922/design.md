# 数据边界与兼容

`closing_trade_plans` 在正常收盘调度中读取正式运行和持仓，再以 `cache_only=True` 读取 qfq
日线。只对当日有效日线运行现有纯规则计划器，结果一次保存到独立快照键。处理上限 115 个
标的、120 秒，外部任务硬超时 180 秒。单股失败保留缺口，禁止启动网络补采或通知。
缓存读取从已打开的文件描述符获取精确写入时间，覆盖文件内可能遗留的属性。该时间必须在
当日 15:00 至本次生成时刻之间；缺失、盘中或未来时间均不能证明收盘输入。

定时快照只接纳与当前交易日、正式运行均匹配的新计划。次日计划优先使用已证明重建的版本，
当天风险复盘继续读取原始计划；二者不互相覆盖。快照生成时间不能替代计划生成时间。

新成交将上海本地时间或显式 offset 归一后再计算指纹及写入 timestamptz。新行在 extra 中
标注时间基准，使读出展示和无指纹兼容查询独立于数据库会话时区。历史未标记行保留旧查询
语义，不依据不完整历史元数据执行批量换区。显式 broker execution ID 仍优先于内容指纹。

参考源核验只认可有限数值和唯一 A 股成员。匹配到相近字段名称不代表指标相同；字段日期
还必须是真实日历日期。每组真实最新性继续由其来源时间表达，不更改五组问句和评分。

不采用“把所有旧计划生成时间改成现在”“重写全部旧成交”或“放宽参考源条件制造 5/5”方案，
因为这些操作会丢失证据并改变业务事实。没有生产部署、外部通知或策略参数调整。
