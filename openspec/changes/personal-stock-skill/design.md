# 归属与调用

`agent/skills/foliant-personal-portfolio` 保存入口、导航和 CLI；`application/personal_skill.py` 保存能力注册、严格参数 schema 及应用调用。业务运算继续使用已有 application/domain 模块，不导入 MCP 或 Web 适配器，不维护两份成交逻辑。

CLI 每次读取私有配置中的固定 actor 和 allow_writes，JSON 通过 stdin，stdout 仅返回 JSON。配置文件与 Foliant 私有数据库运行环境只供受信任的本机进程使用；CLI 不是隔离恶意本机用户的权限边界。查询配置不发现和执行写命令。模型参数不能选择其他 actor、任意模块、SQL 或配置路径。

成交导入内部复用已有暂存批次和提交方法，保持幂等与持仓水位检查，但不把内部批次变成用户审批任务。skill 来源单独标记，旧 Nexus 默认来源保持兼容。中断后按原幂等键与批次回执恢复。

个人策略只修改现有参数；验证类型、数值范围、关联阈值顺序和预期旧值，事务中回读。正式政策发布和研究晋级没有加入该入口。

Losna 通过原生 Cordis 服务装配一个可卸载的 skill 客户端，前台只暴露查询，通用工作按明确委托使用写命令。参数和指导从项目目录动态获取；研究定时器不获得日常权限。未配置、连接失败及中断均不能解释为“没有成交”或“已写入”。
