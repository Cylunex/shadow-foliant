# 设计

`application/research_claims.py` 是数字与证据检查的唯一实现；ResearchCases、MCP 和浏览器
共享结果。提交只接受原始文字、片段、算式、到期时间，服务端生成证据截止时点与核验结果。
发布时间、首次观测与截止时点都用带时区的真实时刻比较。

算术成功只意味着声明口径下的数字可重算，不自动证明来源真实、实体/期间匹配或文字因果。
历史记录的 state 不能绕过新核验；读取不改日志，个别坏记录显示原因而非使整个档案失败。
论点锁定继续沿用现有人工权限、版本检查和幂等行为，不产生新的审批步骤。

未采用新 Agent 框架、全量 RAG、自动来源抓取或 LLM 自评。这些无法解决确定性门禁缺口，
也会增加运行成本和验证范围。
