# Critical only investment notifications

Routine portfolio, selection, source quality and technical reports have produced too many mobile notifications. Keep their analysis in protected snapshots and reserve outbound investment notification for a newly entered, verified highest severity action.

The intraday decision monitor owns the only outbound critical event. Scheduled snapshots remain read only and expose a bounded policy result. Legacy direct transports and the common router close when no certified event is supplied.

This changes the default delivery behavior for all investment channels. It does not alter orders, trade decisions, or the protected scheduled launcher and its slot receipt contract.
