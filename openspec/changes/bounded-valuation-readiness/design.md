# 设计与信任边界

- 同步、选股和健康检查共用估值快照解析器。最新单日快照必须具有有效日期、质量和
  覆盖；缺失当前估值时可使用紧邻的前一个已确认交易日，不拼接、不改日期、不请求外部
  参考来替代正式数据。
- 行情仍须匹配决策上下文的最新完整交易日。估值宽限不会放宽行情/财务/日历/流动性门禁。
- 允许宽限的政策写入 manifest，使用旧快照的 dataset IDs 固定输入。旧 manifest 的政策
  字段缺省为零，保持严格回放。实际估值日期、滞后数在 metadata、readiness、通知公开。
- 补跑成功可表示“降级可选股”；数据库精确入库 quality 仍为 incomplete，保证后续补跑。
  真正没有可用估值的任务为 skipped/source_unavailable，而非程序异常。
- 通知在八行送达预算内，按组合动作优先列股，并为另一侧留一行；重复/冲突买点去除。
  没有合格个股时明确等待，不把组合盘面许可当成个股买入指令。

不采用：把 99% 日线覆盖当成所有数据完整、无限沿用旧估值、把旧估值重标为新日期、
简单增加全站通知长度。这些方案分别会隐藏估值缺口、失效时效门禁或扩大无关消息。
