# 实施与验收清单（0.5.0）

用户已授权实现；本清单区分代码落地和外部验收，不将数据缺失包装成已验证收益。
详细口径见 `docs/RESEARCH_DECISION_LOOP.md`。

## A. 可信基础

- [x] 严格校验重复 JSON 字段/path、bool、非整数、非有限值、累计步长与风险方向。
- [x] 明确五个时点，实际发布之后最早下一交易日开盘，补算不冒充前向。
- [x] 价格后验、MAE、收盘回撤、模型净值与真实证券收益分版本。
- [x] 优化器以相同交易日区间对齐收益，纯计算与在线取数分离。
- [x] generation 绑定的质量报告由任务刷新，健康接口只读缓存。
- [x] Capsule 与原研究工件复用，冻结事实与动态上下文隔离。
- [x] 统一运营限流/跨进程锁/熔断/超时防重入，保留原生供应商硬配额。

## B. 评价与对账

- [x] 共享费用、普通/科创/北交股票数量规则、涨跌停、停牌、现金、容量和公司行为算子。
- [x] 前向 cohort 与连续模型账户独立持久化，处理成交、部分成交、未成交、过期及幂等。
- [x] 同资金和执行规则的 PIT-only、融合、机械去赛道、TOP5、低换手和本地逐策略对照。
- [x] 版本化全账户/证券子账金额对账算子；Web/MCP/Agent 真实日收益共享快照读取。
- [x] contemporaneous / backfilled 及 recorded_at 检查，错过原始执行时点不补造收益。
- [ ] 外部数据验收：完整券商现金流水、逐证券公司行为完整性和特殊品种规则尚未提供；不声称全账户实盘对账或已核实模型净值。
