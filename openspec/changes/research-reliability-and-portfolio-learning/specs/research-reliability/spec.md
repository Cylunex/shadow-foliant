# ADDED Requirements

## Requirement: 兼容的正式选股边界

系统 MUST 保留本地三赛道真实候选、外部参考隔离及用户已确认配额/偏好。
新研究功能 MUST NOT 修改历史正式 artifact，或要求现有选股整体等待新前向样本。

### Scenario: 研究解释模型切换

- GIVEN 本地正式选择已通过其确定性数据与策略合同
- WHEN 解释用 LLM fallback 到未验收模型
- THEN 正式选择保持不变，解释降级为未核验草稿，不冒充已核验研究。

## Requirement: 输入证据可定位且有用途边界

消费方 MUST 验证字段语义、时间、单位与覆盖；MUST 区分空结果、未发布、缺页和失败。
观测记录 MUST 声明准入/物理请求/外部报告/未知粒度，MUST NOT 将同上游包装计为独立证据。

### Scenario: 大部分行情就绪但参考源失败

- GIVEN 必需行情与估值满足该选择协议，问财请求失败
- WHEN 正式选择检查 ready 状态
- THEN 选择可完成，参考标失败，不能被描述为“问财无候选”。

### Scenario: 供应商修订字段

- GIVEN 正式 run 引用旧 manifest
- WHEN 新版本财报或复权数据进入系统
- THEN 新增版本及影响报告，旧事实和选择不被原地覆盖。

## Requirement: 结算可核验性来自输入证据

模型净值 MUST 以实际输入覆盖和支持的事件规则判定，MUST NOT 把未知权益视为无事件。
实际全账户收益 MUST 要求相应现金/权益/费用事实，缺失时保留证券子账边界。

### Scenario: 除息与现金到账不同日

- GIVEN 已核实实施事件、登记权益和分开的除息/到账日期
- WHEN 两个交易日分别结算
- THEN 按版本化规则处理应收和现金，不重复记收益、不提前提供可用现金。

### Scenario: 任务晚跑与目标晚登记

- GIVEN 目标在原执行时点之前已冻结，任务漏跑但后来获得可靠的该日事实
- WHEN 请求恢复模拟
- THEN 可以产生注明恢复时间的模拟修订，不称实际成交；目标本身晚登记时仍是 backfilled。

## Requirement: 研究结论不阻挡风险与记录

Thesis MUST 由用户确认锁定并追加修订；模型 MUST NOT 代替用户确认。
缺论点 MUST NOT 阻挡硬风控减风险、用户自主交易记录或既有成交导入。

### Scenario: 新风险不在旧支柱中

- GIVEN 新证据表明可能存在重大风险但旧论点未登记该变量
- WHEN 执行论点检查
- THEN 产生紧急复核并保留证据，不能只因未映射变量而忽略；硬风控继续执行其规则。

## Requirement: 验证发生而不是仅登记状态

晋级 MUST 引用实际 EvaluationResult 及冻结的协议/候选/输入/成本/执行版本。
搜索计量 MUST 保留失败、指标查看与污染；最终批次 MUST 在揭示结果前占用，使用后不得重置。
系统 SHOULD 按信号类型选择验证方法，MUST NOT 宣称不重叠区间天然统计独立。

### Scenario: 最终评估后进程崩溃

- GIVEN 批次已占用且结果已被评估流程访问
- WHEN 服务恢复
- THEN 只允许原评估幂等恢复或终止，不能交给另一候选重新盲测。

### Scenario: 今日模型生成历史预测

- GIVEN LLM 今日对过去日期生成方向性观点
- WHEN 请求作为当时预测用于严格回测或晋级
- THEN 拒绝回填，保留实际完成时间和探索用途。

## Requirement: 组合对照与 Agent 评测不夸大结论

组合对照 MUST 固定候选、初始状态与改变的情景维度，MUST 披露不可比较因素和交互。
Agent 过程评测 MUST 与纯接口夹具区分；数字、权限和时间硬门不得由语言评分覆盖。

### Scenario: 两条不同但正确的工具路径

- GIVEN 两次研究路径不同但均取得必要证据，数字重算一致且无越权
- WHEN 评估稳定性
- THEN 允许通过硬门，将路径差异记录为诊断，不以逐字/逐步相同为唯一通过条件。

### Scenario: 无充分事实解释收益差异

- GIVEN 真实账户现金或权益事实缺失
- WHEN 比较模型与用户操作表现
- THEN 报告缺口和可比较部分，不能输出完整因果归因或认定用户操作错误。
