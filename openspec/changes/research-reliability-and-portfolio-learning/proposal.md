# Proposal: 研究可靠性、持仓复查与策略学习

状态：Implemented / external acceptance pending。用户已授权实现；未授权本轮推送或部署。
实际交付边界和环境验收缺口见 [0.6.0 说明](../../../docs/RESEARCH_RELIABILITY.md)。

## 动机

0.5.0 已提供数据治理、冻结选股、连续模型账户、实验登记和受控政策调整。
当前缺口主要是可核验结算输入、字段/原文级证据、真正的隔离评估、长期研究对象与实际 Agent 过程评测。
继续横向增加选股源或套用更多 Agent 框架不能解决这些缺口。

## 范围

按六个包逐步扩展现有应用：

1. 数据获取回执、上游家族、字段语义、修订影响与消费方就绪。
2. 公司行为覆盖、执行事实归档与恢复、政策配对证据和可选真实账户对账。
3. ResearchCase、用户锁定论点、证据区块、持仓变化复查。
4. 研究类型协议、真实搜索计量、隔离评估、策略健康与模型时间边界。
5. 不动基线、组合风险快照、成本与执行压力、预测裁决。
6. 真实模型过程评测、受控工具访问留痕、兼容发布与有界调度。

完整设计、源码基线、外部资料及分期验收见
[优化方案](../../../docs/plans/2026-09-04-research-reliability-and-portfolio-learning.md)。

## 兼容与非目标

- 保留本地三赛道、用户策略偏好、PIT 每行业 5 只、TOP15/独立 TOP5、外部参考隔离。
- 保留周度有界进化，不因新样本不足整体停止现有选股。
- 工程功能通过验证即可使用，不引入强制全系统影子等待。
- 不新增券商下单、不恢复 RAG、不重写身份平台、不部署大型图谱/数据湖。
- 不更改盘前/盘中消息篇幅，不将研究前置条件用于阻挡硬风控或真实成交导入。
- 本提案只定义 Foliant 改造；其他仓库接口调整、供应商授权、生产迁移另行确认。
