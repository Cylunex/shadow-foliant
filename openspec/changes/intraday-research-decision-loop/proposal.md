# Proposal: 盘中投研决策闭环

## 动机

正式本地 TOP15/TOP5 已与问财参考隔离，但 09:45 的最终 QQ 通知没有稳定展示五组问财状态和重合项；
10:05 之后的重点池又主要来自异常持仓，无法覆盖当天正式候选。原盘中逐股监控退役后，系统也缺少一条
只用批量报价、可状态化去重、能输出权威价格区间的轻量链路。

## 变更

- 09:45 在正式 TOP5 通知中加入五组问财的有界摘要、失败状态和正式候选重合项。
- 建立真实持仓、正式 TOP5、TOP15 观察级候选的当日统一监控池；问财仅保存在参考分区。
- 从正式选择 manifest 的本地 qfq 日线和既有交易计划/持仓风控规则生成价格计划，报价缺失或陈旧时失败关闭。
- 10:05、11:20、14:30 复用同一决策快照和有界格式；交易时段每 20 分钟仅批量刷新报价和阈值状态。
- 对买入区、止损、止盈、持仓动作升级和整体行情质量降级做交易日内状态化提醒。
- 通过现有快照表保存完整盘中产物，并提供只读 Agent 工具查询。
- 新增 `codex-independent-v1` 独立选股产物：只读正式 run 锁定的 PIT manifest，固定五维权重并按
  必要维度失败关闭，持久化 TOP15/TOP5、分项得分、策略哈希与 1/3/5/10/20 日战绩提名。
- `scheduled-agent-snapshot-v1`、盘中快照和有界 QQ 摘要同时投影独立选股；仅当输入各自有效时计算两两/三方对照。

## 兼容与非目标

- 正式 TOP15/TOP5 的成员、顺序、分数、准入和风险结论保持不变；问财不得进入监控池或提升优先级。
- 不新增券商连接、不自动下单、不在轮询中调用 LLM、问财、F10 或逐股慢 K 线。
- 不新增重复业务表；复用 `indicator_snapshots`、正式 selection artifact、`notification_router` 和 jobs hub。
- 独立通道不读正式或问财的成员、排名和分数；它是可复现研究对照，不是第二个交易执行源。
