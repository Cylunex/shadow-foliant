# 设计与信任边界

历史批量 zzshare/Tushare → 同日收盘批量补缺 → BaoStock 串行历史 PE/PB 补缺。
字段优先级与到达顺序分离；统一市值亿元，仅确证 PE-TTM 进入正式字段。
实时源必须提供真实收盘时间戳，不允许回填其它交易日。净现金流 PCF 与动态 PE 不冒充正式口径。

共享写锁串行化合并；部分行也保存以供续补，完整合并检查点使用一个不可变 dataset。
每条新数据保留字段来源；部分 PE/PB 行不计入正式覆盖。上一交易日整份快照可作为有界备用，
不可把不同日期逐股或逐字段拼接。历史零宽限策略语义不变。

所有来源调用有运行预算，付费源维持共享配额，BaoStock 沿用全主机锁和日请求预算。
SDK 超时只约束其模块与连接，不修改全进程 socket 默认值。失败日志不携带原始异常正文或 URL。

拒绝的方案：实时估值伪装历史、不同市值单位直接合并、每次补跑重查全市场、并发 BaoStock、
对 500 日 bootstrap 自动逐股补齐。相关安全边界由测试和接口契约验证。
