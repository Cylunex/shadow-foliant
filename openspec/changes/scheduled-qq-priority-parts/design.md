# 设计

## 数据流与信任边界

受保护快照提供同批最终动作、原始触发、行情与选股。渲染器只把权威最终动作写成操作；缺执行证据写观察。硬风险观察逐只列出，普通受保护 hold 汇总。完整正文先完成，再按统一字符、UTF-8 字节与行预算分片。

CLI 对整批领取并启动一次 slot。各片顺序通过统一通知路由发送，存档幂等键包含 slot、批次哈希、分片序号；原稿与实际渠道正文在受保护存档中关联。任何不确定结果停止后续片，整批不自动重试。slot 账本记录总片数和已接受片数，`partial` 不等于 `delivered`。

## 边界

没有可证实的更大 QQ 平台限额，继续沿用已验证的 1500 字，并增加 4096 字节限制。只读测试不请求真实 Webhook。HTTP 接受不证明客户端展示。没有变更盘中最高事件、交易门禁、调度时点或通知密钥。
