# ADDED Requirements

## Requirement: 研究和确认可闭环且不越权

系统 MUST 提供已有草稿、调查结果和待确认账户预览的读取路径。
人工复核 MUST 私人隔离、可追溯，不得解除硬风险；重复确认 MUST 幂等。

### Scenario: Agent 草稿由 Web 接续

- GIVEN Agent 保存了带引用的草稿
- WHEN 用户读取并编辑正文后确认
- THEN 引用保留并重算，保存/锁定版本对应，公共查询不暴露私人正文。

## Requirement: 异常结果必须可恢复或明确终止

系统 MUST 区分资料缺失、执行中断和真实完成；旧缺口 MUST NOT 饿死有事实的新独立对照组。

### Scenario: 原日数据后到

- GIVEN 当时已登记意图但缺开盘事实
- WHEN 可靠原日事实归档
- THEN 连续账本与独立组都可恢复，不能用当天行情或永久过期伪装成功。

## Requirement: 评估证据不可绕过协议

严格求值 MUST 绑定冻结候选、版本、成本与时间，拒绝非有限数值和晚于执行的决策。
已揭示盲测 MUST NOT 重新开放；中断允许带原因退役，但不得生成晋级证据。

### Scenario: 开发结果申请晋级

- GIVEN 开发阶段取得正向收益
- WHEN 尚无有效的最终评估
- THEN 只能记录候选就绪，不称正式晋级通过。
