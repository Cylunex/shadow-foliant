# 通俗通知与北向净流入退役

## 动机

现有通知由不同业务模块直接拼接长文本，重复信息和专业术语较多，用户难以快速判断
市场涨跌和是否需要加减仓。北向资金净流入能力仍被晨报、页面和 Agent 引用，但沪深港通
自 2024 年 8 月调整披露机制后已不再公开可计算净流入的实时买卖分项，继续使用第三方
陈旧或推算值会误导研究结论。

## 范围

- 为非存档通知增加统一的通俗化、去装饰和长度限制。
- 晨报只推送一条，固定先说看涨/看跌/震荡及加仓/减仓/不动。
- 午盘简报只保留大盘方向、操作、持仓涨跌和少量强弱项。
- 北向净流入退出采集、正式分析、通知、Web 页面和机器工具。
- 历史数据库表不删除，不进行破坏性数据迁移。

## 兼容性

- `archive` 长文保持原文，不受通知压缩影响。
- 历史数据库和快照中已有 `north_flow` 字段原样保留，但新运行时不再读取或产生新值。
- 删除北向 Web/MCP 查询入口属于有意的能力退役；调用方应改用指数、行业、主力资金、
  龙虎榜和公开新闻事实。
