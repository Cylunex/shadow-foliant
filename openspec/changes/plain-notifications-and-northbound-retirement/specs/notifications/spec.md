# 通知要求增量

## Requirements

### 通俗市场通知

系统 MUST 让主要市场通知先给出市场方向和仓位动作，正文 SHOULD 使用普通投资者可理解的
表达，并限制即时通知长度。

#### Scenario: 晨间通知

- GIVEN 晨间数据分析已完成
- WHEN 发送晨报
- THEN 只发送一条即时消息
- AND 消息包含看涨、看跌或震荡之一
- AND 消息包含加仓、减仓或不动之一

#### Scenario: 长文存档

- GIVEN 消息类别为 `archive`
- WHEN 通过通知路由发送
- THEN 保持完整正文，不应用即时通知行数限制

### 北向净流入退役

系统 MUST NOT 将北向净流入作为正式研究、通知或交易动作的输入。

#### Scenario: 官方买卖分项不可用

- GIVEN 官方只披露北向成交总额而不披露实时买卖分项
- WHEN 生成晨报、午报或选股结果
- THEN 不展示北向净流入
- AND 不因北向数据缺失降低报告完整度
