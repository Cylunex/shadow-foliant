# 数据边界

- `research_master_snapshot_runs.detail.universe_scope` 区分 `current_listed` 与 `lifecycle`。
  当前池可以缺少退市集合，但必须验证上市状态、数量、交易所覆盖和观测时间；不能作为
  事后重建历史全集的证据。原有生命周期发布入口继续拒绝明确不完整的输入。
- 申万分类在同步时按观测/生效/更新时刻筛选，分类值及来源哈希写入不可变证券快照。
  选股和独立量化重放只读清单绑定的快照，不再次读取外部 CSV。
- 新策略清单声明行业规则；旧清单缺少规则标志时保留旧行为。缺少行业、主数据过旧时
  不能将部分分数及失效的行业约束声明为完整可用。
- 模型权重仍为既定五维权重；新增行业比较与数量约束有独立策略版本和哈希。
- 外部研究只通过已有 bundle 接口提交；发送在提交后发生，同一时点发送一次。
- 本地修复不包含生产部署、历史快照重写或证券委托。
