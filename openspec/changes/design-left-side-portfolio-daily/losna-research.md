# Losna 参与选股、策略实验和持仓操作复盘

状态为跨项目设计稿。Losna 负责找出值得核实的机会、主动找反证、提出可回放的改进。Foliant 提供当时可知的数据，保存研究结果，核验风险与执行条件，生成原生通知。这使我们可以逐次回答一个问题：同一份盘面和持仓交给 Losna，比原流程多发现了什么，又避免了哪项错误？

## 一天中各自在做什么

| 时点或触发 | Losna 的具体工作 | 用户看到什么 |
| --- | --- | --- |
| 盘前，数据批次就绪 | 阅读截至当时的公告、财报和盘前已核验问财组，列出待验证的事件、受影响行业和可能的反证。记下本次行业可比口径。 | 只有与今日观察或持仓直接相关的新增事实才占晨报一行。 |
| 早盘研究，10:05 原生报告前 | 盲提名工作只见同批合格全集与公开事实。正式榜发布后的另一份工作才读取正式精选和问财独有标的做点名复核。两者分别列出理由、反证与下一次可观察的条件。 | 研究栏区分“Losna 新发现”“与已有候选重合”“原判断已失效”。价格、指数点位、复核状态取自 Foliant 当批。 |
| 午间和尾盘 | 先查上一次等待的条件，核对行业、个股和市场是否同向变化。私人工作另读最新持仓水位，比较暂持、部分减、整只退出或条件替换的后果。 | 同一只票只显示一个**当前账户动作**，另列 Losna 的不同理由或关注条件。自然日超 15 只仍由 Foliant 在既定渠道交付清仓建议，ETF 另计。 |
| 收盘、指定观察期成熟、每周委员会 | 把原提名与后验配对，区分“事实判断错”“选股对但入场太早”“条件未触发”“执行受限”。选择一个值得试的规则变化，提交预登记实验。 | 日评只解释发生了什么。周评显示哪些改动改善了相同条件下的结果、哪些被淘汰、哪些还需继续观察。 |
| 私聊追问 | 用户问“为什么先看乙、不看甲”时，Losna 取相同报告的来源、候选版本、风险与复核记录。若账户已变化，另取新水位并说明差别。 | 直接回答该次追问，引用时间、差异和下一步。对话答复与渠道是否收到定时报分别留痕。 |

周末清仓建议走原自然日流程。Losna 可引用最近收盘的研究判断并标日期。盘前、盘中、收盘各自只消费在对应截止前已被 Foliant 接收且验证的产物。

## 选股怎样获得真实的独立贡献

1. **建候选池。** Foliant 在同一 `manifest` 和交易日下，以有界、版本化的筛选条件输出合格子集和全池分母。正式 TOP15/TOP5、现有独立量化、问财五组、左侧研究是不同来源。提供一条只读筛选入口，让 Losna 可以发现正式榜外的股票。首版支持已有字段的白名单条件，返回命中数、截取规则、稳定次序与淘汰原因。
2. **提名与挑战。** 分两份工作包。盲提名只收到合格全集的冻结特征和可核查的公开证据，结果锁定后才比较正式/问财成员，将差集标为独有。点名复核则允许看到正式或问财来源，用于找支持和反证，产物明确标“已见名单”。两者使用隔离的执行上下文和记忆，批次内禁止交叉读取。提名后扩展解释时保留已经锁定的名单和名次。首版建议每交易日共深读至多 3 只，至少为盲提名预留一个研究名额，并允许放弃。保留“看过但放弃”的原因。每条研究记录绑定证券、支持与反对证据、首见时刻、适用期限和失效条件。各对照臂使用相同名额与数据预算。问财命中提供点名线索，左侧资格仍须经营/估值支撑及回撤、抛压证据。
3. **校验后发布观察。** Foliant 逐条核对当时的数据来源、交易日、财报期间、计量单位、证券身份和重复提名。引用须能定位到被保存的原文或冻结字段。两篇转述同一公告只计一个独立事实；模型声称“已核实”不构成认证。未完成、驳回和超时照样进入研究覆盖分母。正式榜以其原版本留存，试验期间 Losna 的增删、排序和放弃均保留独立来源。

**用 11 月 3 日的问财结果举例。** 海象新材名列盘前低估值组第一，当日未入正式前 15。Losna 可核对低估是否来自一次性收益、同业折价是否仍成立、下跌时成交量是否收缩。若只能核实第一项筛选名次，早盘候选行可写“海象新材｜问财低估值第 1。经营现金流与抛压仍待核，午间再看”。该例属于点名复核，不计入 Losna 的盲提名成绩。这是设计演例。正式前列但复核否决的股票也可记录反证，保留原复核和来源。

## 怎样优化操作和策略

**先比较可行的操作。** 私人上下文读取账户确认时间、个股/ETF 分类、成本可靠性、当时可卖量、现金、行业暴露、已有硬风险和最终保护结果。Foliant 先给出合法备选和阻断原因，Losna 再说明各方案解决的风险、代价和下一项核查。在分散度已经过高的账户，行业重复且持有理由弱的股票优先复核。报价新鲜、理由证伪也不能替代券商可卖量。卖出部分股份释放 0 个名额，替换必须等整只退出的成交入账，再刷新预算。

例如模拟账户有 18 只个股及 2 只 ETF。甲公司证伪，但当日仅部分可卖。乙公司行业重叠、近期抛压是否收敛尚无足够数据。Losna 对甲报告“可卖部分的降风险方案，释放 0 个名额”，对乙提出下一项查证，保留“暂持”的对照。只有账户预览确认可整只退出且实际成交后，个股数才会从 18 变 17。缺成本的 ETF 仍可展示行情风险，成本驱动的止损等待核实。[账户预览](../../../application/account_preview.py) · [每日账户复盘](../../../application/daily_review.py)

**每次只试一个改变。** 例如“给左侧低估观察增加一个连续缩量条件，能否减少过早入场的最大不利波动？”Losna 在看到结果前登记基础版本、唯一变化、适用市场、主指标、评估日历、费用、失败标准和终止时间。Foliant 用既有 DSL、研究预算和隔离评估器运行；旧规则、现行带 AI 复核的流程、增加 Losna 的流程按共同日期配对。用封存的初始组合核算次一可用报价、滑点、费用、停牌、涨跌停和 T+1。保留不交易、被保护、未成交和负例。研究建议、影子试验、达到准入、既有策略控制器发布、回退各有单独状态。[研究闭环](../../../docs/RESEARCH_DECISION_LOOP.md) · [策略控制器](../../../analysis/strategy_policy_controller.py)

**复盘分两条线。** 个股研究记录“预期验证了什么”，持仓记录“在当时约束下，等、减或退出各有什么后果”。真实成交与未执行的反事实分列。来源过期或结论被推翻时追加修订与失效时刻。只有已经成熟且复核完成的结果可以进入以后批次的研究经验。Losna 可记用户明确表达的左侧偏好和事项引用，个人持仓、行情、收益及其更正以 Foliant 查询为准。

## 两仓之间的接口和身份

Foliant 已有四项领域 Skill、HTTP 能力清单、研究用冻结产物和账户预览。Losna 旧个人 Foliant 接入曾验过持仓读取，包含成交导入的兼容能力。Losna 的 Life 已有 SKILL.md 加 JSON CLI 的接入范例。新增股票协作沿用 Skill + CLI/API，按调用目的分别列出允许的操作。[Foliant 能力清单](../../../agent/manifest.yaml) · [当前外部研究合同](../../../webui/external_research_routes.py)

| 拟增加的 Skill 用例 | 可读、可写的最小范围 | 权威归属 |
| --- | --- | --- |
| 选股研究／策略试验 | 公共冻结候选、行情、公告、评估摘要。只提交独立提名、证据或受支持的实验提案。 | 服务端根据已授权调用方绑定 Losna 作者和策略版本，校验冻结全集及证据，回传产物 ID。 |
| 本人持仓的操作比较 | 用显式账户授权读私人快照与允许的备选。解释自动归入该账户的私有产物，或在私人追问中按需生成。 | 私人适配器与研究写入身份分开。研究身份收不到持仓、现金和私人原文。该工作配置不携带导入成交、发通知、下单或发布正式策略的能力。 |
| 追问与工作恢复 | 可按原工作 ID、研究产物 ID、业务键查询状态。 | Losna 保存工作进度、版本和回执引用。Foliant 分别记录研究产物已接收、正式报告已生成、指定渠道已接受。 |

现有外部研究 writer 把通道固定为 `codex-external-independent-v1`，并要求其独立 TOP15 成员集合精确匹配。该路径有自己的排序修正、新闻观察、调优证据与通知领取逻辑。拟为 Losna 增加独立、带版本的提交与回读合同，复用时点检查、来源去重和事务校验。Losna 独有提名使用其冻结候选集。查询“最新”以及后验统计都必须按生产者、策略版本与运行筛选，回归覆盖旧 Codex 记录。已有 AI 批注可承载说明，但批注内部含创建时间的摘要不能代替可重试的业务键。[外部研究服务](../../../application/external_research.py) · [研究批注](../../../application/research_artifacts.py)

每个工作包带 `job_id, producer, purpose, run_id, manifest_id, decision_cutoff, deadline, schema_version`。模型、提示、筛选定义、上下文类型和可见资料的指纹归入运行记录。产物另带 `subject, evidence_refs, counterevidence_refs, validity, blockers, next_check`，私人操作补账户授权与水位。业务键由服务端按生产者、用途、输入版本和时段确认，同键同正文返回原回执，同键改正文报冲突，更正采用可追溯的新版本。输入切换、水位更新或范围不匹配时拒绝接受原稿为当前意见。

**调度和故障。** Foliant 在产物就绪时登记一份研究请求及截止时间。Losna 的一个受限工作执行者认领，以 Skill 取数和回传，DSH 工作完成后以领域回读确认。固定早盘、盘面告警与超限日报都由 Foliant 发送。Losna 无结果、模型限流或工作超时时，原任务到点照发规则版。迟到结论保留实际首次可知时间，只进下一有效时段或私人详情。接收回执未知先按原键回读，再决定能否重试。用户私聊追问按当前会话回复，同一报告不会再由主动联系队列广播。

Foliant 在同一事务里校验领取代次与未封版状态，写入服务端接收时间、名单锁定时间、结果及回执。重新领取后旧执行者的迟到提交失效。报告按自己的封版时刻读取已验版本并保存实际引用 ID。揭盲只开放已锁结果的比较视图，更正可更新后续说明，不能重开该日原提名。晚于研究截止的消息按迟到样本记录，不能冲抵按时完成数。

**边界在执行器。** 自动投研工作只配必要 Skill、只读数据及窄写入，使用单独工具白名单与凭据，不继承私人聊天通用 Shell、浏览器登录、任意 SQL 或成交通道；这是新增受限执行配置，个人通用工作继续依既有授权运行。公告、网页及模型输出都是待验证材料。来源内嵌的“调用工具/发送/交易”文字不能扩展调用权限。自动任务不得把私有持仓、账户文件或凭据注入公开提名或新增第三方接收方。

服务端逐次校验生产者、工作、用途、阶段、账户和对象归属，覆盖列表、按 ID 查询、引用解析及回执读取。盲提名身份在锁定前无法请求正式榜、问财榜、其他任务结果或私人资料。私人回执和附件不能作为公共研究的引用。超限日报、指数点位与持仓数从 Foliant 的强类型字段渲染。模型补充一条理由或反证，不能通过自写标题或附带文件另发消息。

## 什么结果值得继续投入

| 测什么 | 对照与通过条件 |
| --- | --- |
| 选股是否更早、更准 | 同时冻结原规则、已有 AI 复核、只增加 Losna 的三组结果，分别比较独有、重合、放弃的候选。固定 5 日主窗口，另看 1/3/10/20 日。比较首次可研究到触发的间隔、入场后最大不利波动、扣成本相对收益、覆盖与回撤。 |
| 操作是否更合适 | 在同样账户水位与可交易集合上，比较暂持基线和可行备选。记录错误整只退出数、被规避的风险、退出后反弹、换手、实际释放名额。是否读完报告和是否成交分开计。 |
| 能否进入通知或影响正式政策 | 首先验时点、引文可定位、账户隔离、硬风险一致、准时出报、重复投递和每批成本。严重权限/前视/硬风险冲突立即隔离该产物。研究栏仅接收通过校验的同批事实。增大策略风险沿用原有净收益和封存门，并遵循主设计的跨期预登记门槛。证据不足保留影子，新版本需重测。 |

默认预算是试行值：每日深读至多 3 只，单个时段至多一次综合，周度提出一项实验，受既有配额和截止时间的更严格限制。按日记录候选分母、弃权、超时、模型/资料成本和复核耗时，发现每增加一次模型调用却没有新增可核事实时缩减。正式推送前应先用冻结批次回放、再前向影子观察，分开验证服务可用、通知可读与投资效果。检查点关闭 Losna 即可恢复规则版，已生成的历史证据和通知回执保留。

**交付顺序。** ① 先用只读 Skill 对固定样本走完研究与私人追问，输出留在隔离评估中。② 按生产者、账户和用途验证新窄写入及回读，再前向保存影子产物，统计盲提名与点名复核各自的覆盖。③ 先放行校验通过的解释性一行，实际验收准点、隐私和自然渠道回执。④ 有足够到期证据后才评估研究优先级或政策调整。旧外部研究提案的 20 个成熟样本、4 个 ISO 周和时间切分只决定它能否进入复核。Losna 的策略晋级另走本次预登记的跨期对照及 Foliant 正式控制器的证据、预算、版本校验和回退流程。

控制器仅接受已登记的白名单参数。参数变更通过版本比较及生效日检查后才发布；例如新增“连续缩量”这一策略条件，只能先在隔离试验中验证。即使有效，也须先完成因子注册、代码验证和明确授权的版本发布，才有正式使用入口。
