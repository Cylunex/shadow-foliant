# 个股超过 15 只的每日清仓建议与左侧选股

状态：设计稿，2026-11-03。仅定义行为和验收，不启用任务、不改变选股政策。

用户需要每天知道三个答案：持仓是否过多、优先退出哪只及原因、今天的下跌是值得跟踪的错杀还是原有买入理由已失效。当前正式榜单、持仓分析与市场风控分别已有相当多数据，但从一条消息很难得到一致答案。

- **优先交付**：只数实际持有的个股，场内 ETF 单列。超过 15 只的每个上海自然日都生成并向既有私人渠道推送清仓建议；不依赖选股、模型或交易日历成功。不得为了达标虚构卖出建议。
- **研究与行情**：从正式选股同一冻结股票池增设左侧研究名单。盘面、账户、个股三层证据共同决定如何展示；未验证前不改 TOP15/TOP5、不把新偏好解释成一跌就买。
- **整体体验**：原生通知按时段回答不同问题；网页、个人 Skill 与通知复用同一份有时点的结果。补足影响决策的缺口，分别验收每日送达、选择质量、风险和复盘。

实现只扩展现有 DataHub、持仓、任务、归档与研究服务。不加券商交易、跨项目个人数据同步、新 MCP 或独立审批页。既有 critical/market_risk 即时告警保持独立。
